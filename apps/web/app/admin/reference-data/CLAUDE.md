# apps/web/app/admin/reference-data

CRUD for shared reference tables: grammar points, confusable pairs, vocab, themes. Calls
`app/api/admin/reference-data/**`. Editing here affects every user (these tables aren't
per-user), unlike most of the rest of the app — double-check destructive actions land on the
right table before confirming.

See the root [`CLAUDE.md`](../../../../../CLAUDE.md) for project-wide rules — this file only
notes what's local to this folder.
